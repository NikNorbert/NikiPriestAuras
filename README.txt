NikiPriestAuras 1.8.13
=====================

Animated Priest buff, dispel, Power Word: Shield, Searing Light and Enlightened
reminders for Turtle WoW 1.18.1 / Vanilla 1.12.

Install to:
Interface\AddOns\NikiPriestAuras

Main commands:
/npa set              Open the settings window.
/npa lock             Save positions and lock all elements.
/npa test             Preview Searing Light for 10 seconds.
/npa testenlightened  Preview the Enlightened aura for 10 seconds.

The settings window independently controls the position, size and opacity of
the central icons, Enlightened aura and Searing Light proc. It also provides
icon spacing, proc animation speed, original/custom texture and shield-reminder
options.

The settings interface is Russian on ruRU clients and English on all other
client locales.

See README.md for the complete English documentation.
